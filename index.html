Terminal / Comandos Linux

  1. pwd Mostrar la ruta del directorio actual

    pwd

  2. cd Cambiar de directorio

    cd ~/Downloads

  3. ls Listar archivos/directorios

    ls

  4. cat Mostrar el contenido de un archivo

    cat archivo.json

  5. rm Eliminar archivos

    rm archivo

  6. ssh Conectarse remotamente a otro servidor

    ssh -i labsuser.pem ec2-user@<IP>

  7. exit Cerrar una sesión/shell

    exit

  8. curl Hacer peticiones HTTP

    curl http://169.254.169.254/...

  9. grep Buscar texto o patrones

    grep REJECT archivo.log

  10. nano Editor de texto

    nano script.sh

  11. vim Editor de texto

    sudo vim /etc/ssh/sshd_config

  12. echo Imprimir texto o variables

    echo $sgId

  13. sudo Ejecutar algo con privilegios elevados

    sudo yum install ...
